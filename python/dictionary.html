Dictionary¶

The Dictionary provides read access to a single keyvi file.

from keyvi.dictionary import Dictionary

d = Dictionary("data.kv")
class keyvi.dictionary.Dictionary¶

Keyvi dictionary, an immutable container storing key value pairs, optimized for size, lookup performance and special lookup use cases. A keyvi dictionary has to be created by a previous compile run.

Keyvi dictionaries allow multiple types of approximate and completion matches due to its internal FST based data structure.

complete_fuzzy_multiword(self: keyvi._core.dictionary.Dictionary, query: str, max_edit_distance: SupportsInt | SupportsIndex, minimum_exact_prefix: SupportsInt | SupportsIndex = 0, multiword_separator: SupportsInt | SupportsIndex = 27) → collections.abc.Iterator[keyvi._core.Match]¶
Complete the given key to full matches after whitespace tokenizing,

allowing up to max_edit_distance distance(Levenshtein). In case the used dictionary supports inner weights, the completer traverses the dictionary according to weights, otherwise byte-order.

SecondaryKeyDictionary¶

class keyvi.dictionary.SecondaryKeyDictionary¶

Secondary Key dictionary, a specialized dictionary type that takes additional key value pairs (meta) that are matched exact upfront, enabling use cases like multi-tenancy and personalization.

All lookup methods take a meta parameter, a dict of string to string, to filter entries by secondary keys before performing the actual lookup.

complete_fuzzy_multiword(self: keyvi._core.dictionary.SecondaryKeyDictionary, query: str, meta: collections.abc.Mapping[str, str], max_edit_distance: SupportsInt | SupportsIndex, minimum_exact_prefix: SupportsInt | SupportsIndex = 0, multiword_separator: SupportsInt | SupportsIndex = 27) → collections.abc.Iterator[keyvi._core.Match]¶

Complete the given key to full matches within the secondary key space after whitespace tokenizing, allowing up to max_edit_distance distance (Levenshtein). In case the used dictionary supports inner weights, the completer traverses the dictionary according to weights, otherwise byte-order.
