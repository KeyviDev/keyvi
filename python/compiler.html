Compiler¶

Compilers are used to create keyvi dictionaries from key-value pairs. Different compiler types support different value types.

from keyvi.compiler import JsonDictionaryCompiler

compiler = JsonDictionaryCompiler({"memory_limit_mb": "256"})
compiler.add("key1", '{"value": 1}')
compiler.add("key2", '{"value": 2}')
compiler.compile()
compiler.write_to_file("data.kv")

Parameters¶

All compilers and mergers accept a params dictionary. Values are passed as strings.

Common compiler parameters:

Parameter

Type

Default

Description

memory_limit

int

1 GB

Memory limit in bytes. Also accepts memory_limit_kb, memory_limit_mb, memory_limit_gb.

temporary_path

str

system temp dir

Directory for temporary files during compilation.

minimization

bool

true

Enable FSA minimization. Disabling produces larger output but compiles faster.

parallel_sort_threshold

int

10000

Use parallel sort when key count exceeds this threshold. Set to 0 to disable.

Additional parameters for JsonDictionaryCompiler and FloatVectorDictionaryCompiler:

Parameter

Type

Default

Description

compression

str

none

Compression type: 'zlib', 'snappy', 'zstd', or empty for none.

compression_threshold

int

32

Minimum value size in bytes to apply compression.

floating_point_precision

str

double

JSON only. Set to 'single' for 32-bit floats.

vector_size

int

10

FloatVector only. Number of dimensions per vector.

Merger-specific parameters:

Parameter

Type

Default

Description

merge_mode

str

standard

Set to 'append' for append mode.

class keyvi.compiler.JsonDictionaryCompiler¶

Compiler for creating a dictionary with JSON values.

Accepted params:

  • memory_limit (int): Memory limit in bytes (default: 1 GB). Also accepts memory_limit_kb, memory_limit_mb, memory_limit_gb.

  • temporary_path (str): Directory for temporary files (default: system temp directory).

  • minimization (bool): Enable FSA minimization (default: true).

  • parallel_sort_threshold (int): Threshold for parallel sort (default: 10000).

  • compression (str): Compression type: 'zlib', 'snappy', 'zstd', or none (default: none).

  • compression_threshold (int): Minimum value size in bytes to compress (default: 32).

  • floating_point_precision (str): Set to 'single' for 32-bit floats (default: double precision).
