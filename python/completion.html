Completion¶

Standalone completion classes for more advanced completion use cases. For simple prefix completion, use keyvi.dictionary.Dictionary.complete_prefix() instead.

from keyvi.dictionary import Dictionary
from keyvi.completion import PrefixCompletion

d = Dictionary("completion.kv")
pc = PrefixCompletion(d)
for match in pc.complete("hel", 10):
    print(match.matched_string)
